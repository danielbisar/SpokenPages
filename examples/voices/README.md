# Synthetic demo narrator

The bundled WAV was generated by Daniel Bisar through SpokenPages/VoxCPM from
his own voice-design instructions. It is an artificial voice, not a recording
of the author or another real speaker, and was not copied from a third-party
audio source. It is provided as a synthetic demo/reference, not evidence of
speech-quality evaluation.

The saved voice metadata records:

- Direction: `male, middle-aged, low pitch, studio quality, calm`
- Seed: `42`; inference steps: `30`; no explicit language hint.
- Reference: `3908dd2866c872d18b5b8a4ef8f4e86a27db86634e55ec6a1e508b228da78649.wav`
  (the filename is its SHA-256 digest).

No transcript is recorded with this sample in the repository; one is not inferred
from the app's default test text. These settings document the saved preset; they are not
a guarantee that regenerating it reproduces the same audio.
